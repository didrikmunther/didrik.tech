Exercise 2 from the 2019 KTH Formula Student Driverless exercises, running in Python in your browser. Each plot is h(t) = h·π·e−λ(t) with λ(t) = λ·sin(2πt), drawn by the original LamdaPlot class with numpy and matplotlib. Move the sliders to change its coefficients. Exercise 1 is a ROS publisher and subscriber, which needs a ROS install and can't run here.
